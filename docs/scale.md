# Scale reference

1 block = 1 m for the player and cars. The environment is scaled ×2 (see [decisions.md](decisions.md#scale)).
Sizes are length × width × height in blocks.

| Thing | Size (blocks) | Note |
|---|---|---|
| Player | 0.6 × 0.6 × 1.8 | vanilla, eye height 1.62 |
| Hatchback (car 1, "Sao Mai") | 3.9 × 1.7 × 1.5 | real size |
| Sedan | 4.5 × 1.8 × 1.45 | real size |
| Coupe | 4.4 × 1.9 × 1.3 | real size |
| Pickup | 5.3 × 1.9 × 1.8 | real size |
| Lane | 7 wide | 3.5 m × 2 |
| 2-lane road | 14 + 2 × 2 shoulder = 18 wide | |
| Highway | 4 lanes = 28 + 4 median = 32 wide | plus shoulders |
| Dirt track | 8–10 wide | |
| Storey | 6 high | 3 m × 2 |
| Door opening | 3 high × 2 wide | walkable exception (not ×2) |
| Stair step | 1 high | walkable exception |
| Palm tree | 40–56 tall | 20–28 m × 2 |
| Rice terrace step | 2–4 high | 1–2 m × 2 |
| Snowy peaks | up to about y 560 | stylised, not real ×2 |
| Dimension | y −64 … 639 (height 704) | sea level 63 |
| Map radius | 12 000 | default, see Q3 |
